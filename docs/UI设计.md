# WMS 保税仓储管理系统 — UI 设计

## 1. 设计原则

- 企业级仓储后台：信息密度适中，表格操作为主
- 左侧导航 + 顶栏 + 内容区三栏结构
- 列表页：筛选区 → 操作栏 → 数据表 → 分页
- 表单与详情：居中弹窗，分区字段组，必填标识清晰。与原型一致，不使用侧滑抽屉

## 3. 布局

- 侧栏宽：220px，折叠 64px
- 顶栏高：56px
- 内容区内边距：20px
- 表格行高：约 44px

## 4. 组件规范（原型内）

- Button：主按钮 / 次按钮 / 文字按钮 / 危险按钮
- Input、Select、Date、Upload
- Table + 分页 + 状态 Badge
- Modal 表单与详情（居中弹窗，取消 / 保存或关闭；不使用抽屉）
- Toast（提示条）
- Empty、Loader
- **原型批注**（评审用）：顶栏「显示/隐藏批注」+ 「批注列表」侧栏；**右键页面任意处**添加批注；弹窗仅输入框；橙色序号 Pin；**完成后 Pin 自动隐藏**，列表可查看；点击列表项定位并高亮落点；**远程同步**统一走线上 `http://wms.skd.wang/api/annotations`（本地预览同样请求该地址，线上同源仍用相对路径）；本地缓存兜底；支持导出/导入 JSON

## 5. 页面清单（原型）

1. 登录（无生产员）；系统设置可全站注册账号；登录态存 `sessionStorage`（`wms_auth`），同标签页刷新保持，退出清除
2. **可视化驾驶舱（主页）**：科技风 HUD，仓库堆位热力 / 入出库趋势 / 作业流水 / 关务账实 / 预警
3. 基础数据：仓库管理（1/2/4/5/6 仓及码头仓库；列表含面积㎡，仅展示可编辑）、堆位管理（单仓库展示；档案列不含报关单号/生产批次/占用率/查验状态；列表展示网格行列，新建/编辑弹窗不展示网格字段）、物料档案、往来主体（**流向企业由出库字段自动录入**；**不含统一社会信用代码**）、保税账册（**货值、报关单号**；点击编号查看票矿并可导出；新账填旧账预警日，旧账只出不进；**列表可按关键字、旧账预警时间范围筛选**）、系统参数与角色（配置权限弹窗按菜单分组勾选）、**账号管理**（全站注册，无所属关区）、**平面图设置**（系统设置 Tab：CAD 网格画板，右上角保存 / 设置网格像素 / 帮助）
4. 入库：预约/收货列表（筛选：时间范围、货运方式、矿种；状态：**暂存码头 / 待收货 / 已入库 / 混成品**；列含矿种、五项有害元素、装运方式、柜数；**无片区标识**）、收货登记、预定堆位（弹窗右侧、**可关键字搜索**）及**按平面图格子圈选存放位置**、**OCR 回填**；**预约与到货登记弹窗不含五项有害元素**；原料库存批次取**报关单号**；已入库/混成品「详情」查看本票单证
5. 移库：先选原堆位再选批次；**批次信息（委托方/报关单号/生产批次/物料/船名/柜数）以表格只读展示**；**批量移库可跨仓勾选**（仓库/堆位/委托方/关键字查询）；批量每票单独成单；列表可按**委托方、时间范围**筛选；列表含船名、柜数；移库时间为起止到时；无操作人/详情
6. 库存：多维查询（时间范围：**本月**或自定义起止精确到时）、货物类型原料为达标矿/报备矿、**成品为混成品**、本票品质 **八项**（Cu/Ag/Au/As/Pb/Cd/F/Hg）、本票详情含报关单/重量证书/品质证书及**成品**页（原料投入后的成品、库存、出库）、盘点（**无类型字段，范围可多选仓库与堆位，可上传附件，不回写库存、无账实差异**；**可按月份导出各委托方在库数量、堆位、货物类型、提单号、报关单号**）、按报关单号/生产批次号的重量台账（出库记**流向企业**）、预警；列表**不含类型列**；**成品原产国为 —**；**已出库堆位为 —**
7. 生产：**投料出库与加工过程合为一项列表**（可按委托方、时间范围筛选）；**完工入库只允许进入待检区**；**查验完成**后片区标识改为**成品区**；台账；**同一生产批次号可勾选多个报关单号矿物**；投料行含**出库报关单号**；物料/船名航次/提单号/来源国家在详情；投料展示**达标矿/报备矿**、加工展示工序；成品库存批次即生产批次号
8. 出库：订单列表与审核；**OCR 回填**（出库报关单 → 报关单号/核注清单号/流向企业/**消费使用单位**/重量/**报关单金额**）；列表**时间范围**筛选；识别字段均可手工修正并**操作留痕**；备注选填
9. 关务：账实对账、差异报表
10. OCR 中心
11. 对接配置
12. 操作日志审计
13. **开发进度跟踪**（系统）：以能力跟踪表为基线提交六轨进度；甘特图（模块 / 批次 / 目标节点 / 能力）与两张可切换维度的柱状图随筛选与提交同步刷新；变更日志记录修改者、来源 IP、修改时间及字段前后值（IP 与时间由服务端写入）

### 5.1 投标功能响应原型补充

- **物料档案**页：原料货物类型（达标矿/报备矿）、成品货物类型**混成品**、矿源；不展示原产国、备案号、商品编码、品质参数。**新建/编辑弹窗仅基础信息**（编码、名称、货物类型、类型，报备矿填矿源），不含干湿重规则、默认账册、单证样例字段。工具栏可**导出 Excel**（编码/名称/货物类型/类型/矿源）。**矿源备案** Tab 含备案原产国、备案数量、核销/剩余吨数、用量%、**生产批次号**、**附件**；列表可按矿源、编号、状态、**备案日期时间范围**筛选；备案编号可点击查看该备案下全部票货（含生产批次号）并可导出 Excel；同一矿源多期备案。入库按矿源自动匹配备案；品质参数在库存本票（上架后）展示
- 仓库管理列表展示编号、库容、**面积(㎡)**、堆位数、占用率；面积仅档案展示，弹窗可编辑，不参与库容占用计算。堆位档案列表展示编码、所属仓库、片区标识、网格、库容、状态（不展示报关单号、生产批次、占用率、查验状态）；**网格行列取自平面图设置中该堆位所占画板格**，列表只读展示，**新建/编辑弹窗不展示网格字段**；查验完成触发片区标识变更（**待检区→成品区**，仅三类：原料区/待检区/成品区）；片区标识变更历史在操作日志页。堆位列表仅展示当前所选仓库（默认 1 仓）。园区平面图在**系统设置 · 平面图设置**：整幅 CAD 网格，不再放右侧工具栏。右上角为保存、设置、帮助；设置弹窗只改网格 px，并写入平面图。左侧切换「绘制 / 框选」。绘制时左键须拖拽才按格吸附生成区块，只点击不生成；右键设置名称、是否仓库，背景色从 12 个色块中选择（规定色加马卡龙色），宽高同一行按 x × y 填写，并可拖动角点缩放。框选时左键拉框并高亮相交区块，右键菜单为拖拽、缩放、删除。名称弹窗与框选菜单靠近画板底部、向下放不下时改为向上展开；靠近右侧、向右放不下时改为向左展开。**仓库名称在区块外底部居中**，其余名称在左下角且图层在上。画在仓库内的区块为堆位，保存后把所占行列同步到堆位管理，入库按该网格圈选。滚轮缩放，空格拖拽平移。驾驶舱网格铺满示意图区域。未放大时点击仓库或堆位都放大该仓，不进入堆位管理；放大后只显示该仓及其内部区块，其它区块隐藏，此时点击堆位才进入堆位管理。
- 移库页：先选原堆位再选批次；选中后委托方、报关单号、生产批次、物料、船名、柜数以表格只读展示；**批量移库可勾选各仓库矿批次**，并按仓库/原堆位/委托方/关键字查询；批量移库每票单独成单；列表可按**委托方、时间范围**筛选；列表含船名、柜数与起止到时，无操作人/详情。库存页提供报关单号/生产批次号重量台账详情（出库流水含流向企业）；预警页按 **库容 70%**、**原料库龄 90 天**、**码头仓库 7 天** 规则展示。系统参数含码头仓库预警天数（默认 7）。
- 关务页提供账实差异穿透明细；对接配置页**必预留海关、物流端口**，扩展园区/ERP/生产系统。
- 操作日志页提供修改前后值、业务单号、来源地址和关务专用账号标识等审计详情；筛选支持**时间段**（起止日期）与模块快捷标签；日志**永久留存**，系统参数不配置保留年限。系统参数 Tab 仅含库容预警、原料库龄、矿源备案用量预警、品质参数配置，不含盘点差异自动生成。
- 上述补充界面沿用浅色企业后台表格、弹窗、状态 Badge 和 8px 间距体系，不修改基础组件默认视觉。

### 6.2 布局（12 栅格）

- 顶栏：标题「保税仓储可视化驾驶舱」+ 实时时钟 + LIVE 心跳
- KPI 条：6 张指标卡（原料湿/干吨、成品干/湿吨、今日入库、今日出库、待检、预警）
- 中左（8 列）：仓库堆位示意图（放大展示 5 仓拼接园区平面图，上层绘制各堆位格子的在库货物与入库预约；图内右上角**卫星图开关**）
- 中右（4 列）：仓储作业链路（加高日志滚动区，时间精度到「年月日时」、不含分钟）+ **生产数据**卡片（基于原图循环施工视频 + 生产批次号/总量/累计重量 KPI）
- 底栏：近 7 日入出库趋势（图例统一为入库湿吨 / 出库湿吨）、**仓库使用分布**（各仓库占用进度条，无饼图）、预警（与作业链路相同：无缝循环向上滚动，悬停暂停）

### 6.3 交互

- 堆位悬停：编码、片区标识、物料、占用率、库容、预约格数
- 默认整园视图；点击仓库或堆位进入该仓库观察（镜头动画放大后**仅绘制本仓库**）；放大后左上角「回退」动画回到园区
- 放大后：点击堆位（空闲格/堆位块）进入堆位管理；点击在库矿物格子跳转库存查询并定位该票
- 卫星图开关：平面图右上角切换航拍风格（卫星底图 + 屋面波纹/堆场砂土画法、矿物格圆角）；关闭后恢复平面填色
- 驾驶舱仓库堆位示意图按 Figma 该区块填色，不沿用平面图设置的浅色画板。仓库 `#373e52`、空闲堆位 `#566286`、门 `#62646e`，文字白色。混矿线 `#9c7c54` 斜纹，成品区 `#a58136` 斜纹，设备区 `#585b72` 斜纹。图例：五矿有色 `#c87348`、南国铜业 `#2e80d9`、广西金川 `#30b0c7`（达标描边 `#5aed95`），混成品 `#a88354`，入库预约金虚线 `#d1c040`，空闲 `#566286`
- 首页平面图在远程数据返回前显示工业风扫描加载（雷达/格线/扫描条），不先绘制默认园区图再替换；加载动画至少展示 2 秒
- KPI / 预警点击跳转对应业务页
- 作业链路日志自动向上滚动播放，悬停暂停；时间展示为 `yyyy-mm-dd HH时`
- 底栏预警列表同样无缝循环向上滚动，悬停暂停；点击条目跳转对应业务页
- 生产全链路节点按序高亮，连线虚线流动
- 进入驾驶舱时数字滚动、热力微动；离开后停止定时器
- 顶栏、内容区在驾驶舱页切换为深色 HUD，侧栏保持原深色并加强青色描边

## 7. Vue 前端（`frontend/`）

Figma 只提供整体风格。侧栏 `#101217`，系统概览底 `#14171c` 并按概览区块排布；其余业务页使用第 2 节配色和 Element Plus 的筛选、表格、分页、弹窗，不按 Figma 画板逐屏还原。

- 菜单中的仓库档案命名为「仓位管理」
- 新建、编辑、详情、完工入库、查验完成、配置权限均使用居中弹窗，交互对齐原型：账册编号与备案编号点击后弹窗查看并可导出；角色权限在列表中点「配置权限」弹窗勾选。不使用抽屉或单行输入框代替表单弹窗
- 滚动条：业务页为 8px 细条，滑块 `#B9C9DB`、悬停 `#1B4F8A`，轨道透明；驾驶舱内 Element Plus 滚动条用金 `#D1C040`。侧栏菜单可滚动，但隐藏滚动条
- 不实现对外对接、开发进度跟踪、系统架构，也不移植原型批注
- 平面图设置为整幅画板，不再使用右侧网格和区块工具栏。左侧为「绘制 / 框选」，右上角为保存、设置、帮助。设置弹窗只填写网格 px。绘制模式下左键按下后须拖拽，松开才按格吸附完成区块，只点击不生成。右键设置名称、是否仓库，背景色从 12 个色块中选择（规定色加马卡龙色），宽高同一行按 x × y 填写，并可拖动角点缩放。框选模式下左键拉框，松开后高亮相交区块；右键菜单为拖拽、缩放、删除。名称弹窗与框选菜单靠近画板底部、向下放不下时改为向上展开；靠近右侧、向右放不下时改为向左展开。仓库名称在区块外底部居中，其余名称在左下角且图层在上。画在仓库内的区块为堆位，保存后把所占行列同步到堆位管理；入库预约按该网格圈选格子。画板底 `#F0F3F7`、网格 `#D8DEE8`，仓库默认 `#F8E4C5`。驾驶舱网格铺满示意图区域。未放大时点击仓库或堆位都放大该仓，不进入堆位管理；放大后只显示该仓及其内部区块，其它区块隐藏，此时点击堆位才进入堆位管理。卫星图开关保持不变。概览填色仍按 Figma「仓库堆位示意图」。
