# WMS 保税仓储管理系统 — UI 设计

## 1. 设计原则

- 企业级仓储后台：信息密度适中，表格操作为主
- 左侧导航 + 顶栏 + 内容区三栏结构
- 列表页：筛选区 → 操作栏 → 数据表 → 分页
- 表单与详情：居中弹窗，分区字段组，必填标识清晰。与原型一致，不使用侧滑抽屉

- 侧栏宽：220px，折叠 64px
- 顶栏高：56px
- 内容区内边距：20px
- 表格行高：约 44px

## 4. 组件规范（原型内）

- Button：主按钮 / 次按钮 / 文字按钮 / 危险按钮
- Input、Select、Date、Upload
- Table + 分页 + 状态 Badge
- Modal 表单与详情（居中弹窗，取消 / 保存或关闭；不使用抽屉）
- Toast（提示条）
- Empty、Loader
- **原型批注**（评审用）：顶栏「显示/隐藏批注」+ 「批注列表」侧栏；**右键页面任意处**添加批注；弹窗仅输入框；橙色序号 Pin；**完成后 Pin 自动隐藏**，列表可查看；点击列表项定位并高亮落点；**远程同步**统一走线上 `http://wms.skd.wang/api/annotations`（本地预览同样请求该地址，线上同源仍用相对路径）；本地缓存兜底；支持导出/导入 JSON

## 5. 页面清单（原型）

业务页顶部不放说明提示条。弹窗里的字段说明和操作反馈仍保留。

1. 登录（无生产员）；系统设置可全站注册账号；登录态存 `sessionStorage`（`wms_auth`），同标签页刷新保持，退出清除。连续登录失败达到安全策略次数后，本机锁定该账号并在登录页倒计时，锁定期间不再提交。登录后无操作达到空闲时限，提前 1 分钟提示，超时清除登录态并退出
2. **可视化驾驶舱（主页）**：科技风 HUD，仓库堆位热力 / 入出库趋势 / 作业流水 / 关务账实 / 预警
3. 基础数据：仓库管理（1/2/4/5/6 仓及码头仓库；列表含面积㎡，仅展示可编辑；操作列可启用、停用、删除）、堆位管理（单仓库展示；片区标识选项来自字典；操作列可删除，无启用停用；档案列不含报关单号/生产批次/占用率/查验状态/状态；列表展示网格行列，新建/编辑弹窗不展示网格和状态）、物料档案、往来主体（**角色选项来自企业类型字典**；**流向企业由出库字段自动录入**，列表仍可启用或停用，手工维护的可删除；**不含统一社会信用代码**；新建/编辑弹窗字段各占一行，不含状态，新建默认启用）、系统参数与角色（共用左侧导航面板：左侧点选，右侧换内容，切换时内容横向淡入。角色权限勾选文字保持深色，不含生产与关务）、**账号管理**（全站注册，无所属关区；注册/编辑弹窗字段各占一行；密码按安全策略校验；列表可启用或停用）、**安全策略**（放在系统参数左侧：密码长度与复杂度、连续失败锁定、空闲退出；保存在本机浏览器）、**平面图设置**（系统设置 Tab：CAD 网格画板。工具条跟随主题色，左侧为深色图标条：仓库、堆位、普通区域、门、框选，当前项为主色方块，右侧为同一深色图标条：初始化、设置、帮助，保存为主色方块，悬停显示名称。帮助按绘制、仓库与堆位、门、初始化、框选、名称、快捷键分块）
4. 入库：列表仍可按时间范围、货运方式、矿种筛选，状态为**暂存码头 / 待收货 / 已入库 / 混成品**。新建和收货用**接近全屏的大弹窗**（约 94% 视口宽、90% 视口高），列表留在后面。弹窗内仍是四步：顶栏进度**放大并居中**（基本信息、设置堆位、重量单、品质单），浅灰底、白卡片、圆角 8px，底部「上一步 / 下一步」。**第 1 步**填委托方、船名、提单、金额、物料、矿种、装运方式，**不填物流账册主体和匹配账册**。报关单、重量证书、品质证书共用独立的 OCR 上传组件，**不提供提单上传**。拖拽或点击上传后，图片在预览区里可放大、缩小、旋转和拖动查看，滚轮也可缩放。OCR 暂不可用，上传后用 mockjs **随机生成**并回填。**入库货品都是原料**，物料只列出原料，不选成品。**第 2 步**用驾驶舱仓库放大：先看整园，点击仓库镜头放大并只画该仓，再在堆位上拖拽框选格子作为存放位置。**第 3 步**上传重量单并核对湿重、干重、水分。**第 4 步**上传品质单并核对品质参数。已入库或混成品仍从列表进详情。待收货、暂存码头从「收货」进入第 3 步。原料库存批次取**报关单号**
5. 移库：先选原堆位再选批次；**批次信息（委托方/报关单号/生产批次/物料/船名/柜数）以表格只读展示**；**批量移库可跨仓勾选**（仓库/堆位/委托方/关键字查询）；批量每票单独成单；列表可按**委托方、时间范围**筛选；列表含船名、柜数；移库时间为起止到时；无操作人/详情
6. 库存：多维查询（时间范围：**本月**或自定义起止精确到时）、货物类型原料为达标矿/报备矿、**成品为混成品**、本票品质 **八项**（Cu/Ag/Au/As/Pb/Cd/F/Hg）、本票详情含报关单/重量证书/品质证书及**成品**页（原料投入后的成品、库存、出库）、盘点（**无类型字段，范围可多选仓库与堆位，可上传附件，不回写库存、无账实差异**；**可按月份导出各委托方在库数量、堆位、货物类型、提单号、报关单号**）、按报关单号/生产批次号的重量台账（出库记**流向企业**）、预警；列表**不含类型列**；**成品原产国为 —**；**已出库堆位为 —**
7. 生产：侧栏放在**仓储作业**，菜单名**生产加工**，页面不放提示条。**投料出库与加工过程合为一项列表**（类型、单号、委托方、生产批次、报关单号、出库报关单号、货物类型/工序、数量、堆放堆位、生产工单、时间；可按委托方、时间范围筛选）。投料按报关单一行，数量为湿重/本次干吨；加工为一行，数量为起止时刻，报关单为「首票 等 N 票」。点**详情**打开**生产批次详情**：关联报关单表（序号、报关单号、出库报关单号、委托方、货物类型、物料、船名/航次、提单号、来源国家、湿重、干重、堆放堆位、片区标识）和完工入库（完工单号、生产批次、目标堆位、投料消耗）。投料弹窗为两列：委托方、生产批次、生产工单、已选报关单，下方可按报关单号、货物类型、来源国家、堆放堆位筛选并重置，勾选后填写本次干吨，不得超过可用干吨。加工登记为两列：委托方、生产批次、工序、起止时间，下方为该批次**混矿原料信息**，底部为备注。完工入库为两列：委托方、成品物料、产量、生产批次、关联报关单、待检区目标堆位，下方为关联报关单矿物；完工列表含原料堆放堆位、目标堆位、片区标识，操作只有详情。查验完成在堆位管理。消耗产出台账按日汇总，点**明细**看当日单据。成品库存批次即生产批次号
8. 出库：订单列表与审核；**OCR 回填**（出库报关单 → 报关单号/核注清单号/流向企业/**消费使用单位**/重量/**报关单金额**）；列表**时间范围**筛选；识别字段均可手工修正并**操作留痕**；备注选填
9. 关务：账实对账、差异报表
10. OCR 中心
11. 对接配置
12. **系统**：系统设置在字典管理上方（不在基础数据）。字典管理在预警日志上方，版式按 Windows 11 设置：左侧为字典类型导航（顶部查找，选中项为圆角浅底并跟随主题色），右侧大标题为当前类型，其下是该类型的字典值。可新建、编辑、删除，并可刷新缓存。状态为正常或停用。页面不放提示条。预警日志在操作日志上方，版式与字典管理相同：左侧为预警类型导航（全部、库容、库龄、码头超期、备案用量，顶部可查找，选中项为圆角浅底并跟随主题色），右侧大标题为当前类型，其下白卡片列出预警记录。卡片内筛选级别、对象和时间段。列表列为时间、级别、类型、对象、说明。查看进入对应业务页。页面不放提示条。操作日志在其下，版式与字典管理相同：左侧为模块导航（全部、生产、移库、堆位、入库、出库、关务、基础数据、权限，顶部可查找，选中项为圆角浅底并跟随主题色），右侧大标题为当前模块，其下白卡片列出操作记录。卡片内筛选操作人、业务单号、报关单号、生产批次、仅关务和时间段。列表列为时间、操作人、模块、业务类型、业务单号、操作内容、留痕详情。详情为操作审计弹窗。页面不放提示条
13. **账务**：侧栏独立分组，页面不放提示条。保税账册版式与字典管理相同：左侧选账册，右侧是账册记录，**备案账册**在右侧。备案只填账册编号、账册名称和旧账预警日，默认衔接当前在用账册；保存后旧账册**停用**，只把在册未出库的票货转入新账册。月度账册只查询，不填月份时查看 2026-08；当月有耗用标**已出清**且次月**不再纳入**，未耗用标**未出清**并继续出现。月度账册可按当前筛选导出 CSV，点详情查看原料存储、加工、出库记录
13. **开发进度跟踪**（系统）：以能力跟踪表为基线提交六轨进度；甘特图（模块 / 批次 / 目标节点 / 能力）与两张可切换维度的柱状图随筛选与提交同步刷新；变更日志记录修改者、来源 IP、修改时间及字段前后值（IP 与时间由服务端写入）

### 5.1 投标功能响应原型补充

- **物料档案**页：货物类型、类型的下拉来自字典。原料货物类型（达标矿/报备矿）、成品货物类型**混成品**、矿源；不展示原产国、备案号、商品编码、品质参数。列表按货物类型、类型、物料编码/名称筛选，操作列可删除。**新建/编辑弹窗字段各占一行**（编码、名称、货物类型、类型、矿源）。原料从智利精矿、澳洲精矿中选择矿源；成品不填矿源，不含干湿重规则、默认账册、单证样例字段。成品货物类型锁定为混成品。工具栏可**导入 CSV**、**导出 Excel**（物料编码/名称/货物类型/类型/矿源）。**矿源备案** Tab 列顺序为矿源、备案原产国、矿源备案编号、备案日期、状态（有效/即将用尽/已用尽）、备案数量、核销吨数、剩余吨数、用量%、附件；操作有票货、编辑、查看附件。列表可按矿源、编号、状态、备案日期起止筛选。备案编号可点击查看该备案下全部票货（报关单、生产批次号、委托方、物料、货物类型、堆位、湿重、干重、入库时间、状态）并可导出 Excel。新建时编号自动生成，核销、剩余、用量、生产批次号只读。同一矿源多期备案。入库按矿源自动匹配备案；品质参数在库存本票（上架后）展示

- 移库页：先选原堆位再选批次；选中后委托方、报关单号、生产批次、物料、船名、柜数以表格只读展示；**批量移库可勾选各仓库矿批次**，并按仓库/原堆位/委托方/关键字查询；批量移库每票单独成单；列表可按**委托方、时间范围**筛选；列表含船名、柜数与起止到时，无操作人/详情。库存页提供报关单号/生产批次号重量台账详情（出库流水含流向企业）；预警页按 **库容 70%**、**原料库龄 90 天**、**码头仓库 7 天** 规则展示。系统参数含码头仓库预警天数（默认 7）。

- 菜单中的仓库档案命名为「仓位管理」
- 新建、编辑、详情、完工入库、查验完成、配置权限均使用居中弹窗。账册编号与备案编号点击后弹窗查看并可导出；角色权限在系统设置中左侧选角色、右侧勾选菜单，不再使用配置弹窗
- 除平面图设置和驾驶舱仓库堆位示意图外，业务页按原型分页交互：入库为接近全屏的大弹窗，弹窗内四步，不再把预约和到货收货拆成两个小弹窗；移库先选堆位再选批次，批量按票指定目标堆位；库存详情与台账分开；盘点多选范围并上传附件；生产分投料/加工、完工入库、消耗产出；出库须先识别报关单，审核后再出库完成；OCR 为上传区加修正弹窗；关务先看汇总再查明细。平面图绘制、框选和驾驶舱放大下钻保持现有画板，不按原型右侧工具栏改写
- 滚动条：业务页为 8px 细条，滑块 `#B9C9DB`、悬停 `#1B4F8A`，轨道透明；驾驶舱内 Element Plus 滚动条用金 `#D1C040`。侧栏菜单可滚动，但隐藏滚动条
- 不实现对外对接、开发进度跟踪、系统架构，也不移植原型批注
- 平面图设置为整幅画板，不再使用右侧网格和区块工具栏。左侧为深色图标条（仓库、堆位、普通区域、门、框选），右上角为初始化、设置、帮助、保存图标，悬停显示名称。点击保存时画板盖上科技风扫描（雷达、格线、扫描条、角标框，同驾驶舱平面图加载），暗色并铺满整块平面图，描边和雷达用驾驶舱金。设置弹窗只填写网格 px，不放说明。区块设置只留字段，说明写在帮助里。仓库和堆位画笔左键拖拽松开后按格生成区块。普通区域不设初始长宽，拖出的范围就是大小。左键单击区块或仓库即选中，设置弹窗出现在该区块外侧，不盖住区块；绘制松开后同样弹出，并自动聚焦名称，名称可回车换行。选中后再左键拖动是移动该区块或仓库，不会绘制新区块；拖动仓库时仓内区块一起移动。未选中时拖动仍会绘制。右键也可打开该设置。背景色快捷项取驾驶舱实色和斜纹（仓库、空闲堆位、门、五矿、南国、金川、混成品、绿色区块、预约金、混矿线、成品区、设备区），其中灰、五矿、南国、金川、混成品和绿色为 60% 透明，画板为暗色，选中时四角为金色折角，长度随区块宽高缩短，宽高同一行按 x × y 填写，并可拖动折角缩放。门固定一格长、三分之一格宽，默认 1号门、2号门，填色默认用快捷色里的蓝 `#2e80d999`，设置弹窗可绕中心旋转 90 度，不强制吸附网格，边线距网格线 2 像素内时自动贴上，靠在仓库上时允许溢出一个门宽。普通区域与门一样可按小数摆放。仓库和堆位不能改成普通区域或门。门内名称顺着长边排列：扁门横排、窄门竖排，字号随门的宽高缩小，不超出门框。框选模式下左键拉框，松开后高亮相交区块；右键菜单为拖拽、缩放、删除；Del 删除选中区块，删除仓库或堆位前再确认一次。右键仓库可「初始化堆位」。名称弹窗与框选菜单靠近画板底部、向下放不下时改为向上展开；靠近右侧、向右放不下时改为向左展开。仓库名称在区块外底部居中。堆位名称仍在左下角，库容吨位为右下角小字水印。门以外的普通区块（过道、设备、生产线等）名称在块内居中，字号随宽高缩小，窄块竖排，字与字不重叠。区块互相压住时，文字改放到重叠区之外，例如中控室的字避开卫生间。图层在仓库之上。仓库画笔绘制后弹出库容（吨）和面积（㎡）。堆位画笔在仓库内绘制且大部分格子落在仓内时直接标为堆位，按所占格子占该仓库的百分比把仓库库容向下取整作为堆位库容，并以小字水印标在堆位右下角；改堆位宽高、拖动角点，或改仓库库容和仓库大小，都会重算；保存只把改过的编码、所属仓库、库容同步到堆位管理，不再查询档案列表；入库预约按该网格圈选格子。门、过道、设备、生产线不写入档案。取消仓库、堆位或删除区块后，点击保存会删除对应档案：先提交堆位删除，再提交仓库删除。右上角「初始化」先清空平面图，再读取全部仓库和堆位，按库容占用画板格子并留白 30%，堆位再按库容平分所在仓库，不保留道路、办公楼等默认区块。右键仓库「初始化堆位」读取该仓库堆位档案，避开已画的过道、设备等占用，按库容把剩余空位分给各堆位并绘制。画板底 `#F0F3F7`、网格 `#D8DEE8`，仓库默认 `#F8E4C5`。驾驶舱网格铺满示意图区域。未放大时点击仓库或堆位都放大该仓，不进入堆位管理；放大后只显示该仓及其内部区块，其它区块隐藏，此时点击堆位才进入堆位管理。卫星图开关保持不变。概览填色仍按 Figma「仓库堆位示意图」。
