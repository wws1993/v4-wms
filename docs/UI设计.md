# WMS 保税仓储管理系统 — UI 设计

## 1. 设计原则

- 企业级仓储后台：信息密度适中，表格操作为主
- 左侧导航 + 顶栏 + 内容区三栏结构
- 列表页：筛选区 → 操作栏 → 数据表 → 分页
- 表单页/抽屉：分区字段组，必填标识清晰

## 3. 布局

- 侧栏宽：220px，折叠 64px
- 顶栏高：56px
- 内容区内边距：20px
- 表格行高：约 44px

## 4. 组件规范（原型内）

- Button：主按钮 / 次按钮 / 文字按钮 / 危险按钮
- Input、Select、Date、Upload
- Table + 分页 + 状态 Badge
- Modal / Drawer 表单
- Toast（提示条）
- Empty、Loader
- **原型批注**（评审用）：顶栏「显示/隐藏批注」+ 「批注列表」侧栏；**右键页面任意处**添加批注；弹窗仅输入框；橙色序号 Pin；**完成后 Pin 自动隐藏**，列表可查看；点击列表项定位并高亮落点；**远程同步**统一走线上 `http://wms.skd.wang/api/annotations`（本地预览同样请求该地址，线上同源仍用相对路径）；本地缓存兜底；支持导出/导入 JSON

## 5. 页面清单（原型）

1. 登录（含海关专用账号入口提示）；登录态存 `sessionStorage`（`wms_auth`），同标签页刷新保持，退出清除
2. **可视化驾驶舱（主页）**：科技风 HUD，仓库堆位热力 / 入出库趋势 / 作业流水 / 关务账实 / 预警
3. 基础数据：仓库管理、堆位管理（单仓库展示；平面图管理弹窗）、物料档案、往来主体、保税账册、系统参数与角色（配置权限弹窗按菜单分组勾选）
4. 入库：预约/收货列表、收货登记、**OCR 回填**（预约：提单/报关单 → 船名/提单号/报关单号/核注清单号/金额；收货：重量单 → 湿重/干重/水分，品质证书 → Cu 品位/证书号）、称重与片区分配；上架后原料库存批次取**报关单号**；已称重/已上架「详情」查看本票报关单、重量证书、品质证书及参数
5. 移库：移库单列表与新建（对象为报关单号或生产批次号）
6. 库存：多维查询、本票单证详情、盘点、按报关单号/生产批次号的重量台账、预警；列表含**批次类型**
7. 生产：投料、加工、完工入库、台账；**同一生产批次号可勾选多个报关单号矿物**；成品库存批次即生产批次号
8. 出库：订单列表与审核；**OCR 回填**（扫描出库报关单 → 出库报关单号/核注清单号/流向企业/重量）
9. 关务：账实对账、差异报表
10. OCR 中心
11. 对接配置
12. 操作日志审计

### 5.1 投标功能响应原型补充

- **物料档案**页：货物类型（达标矿/报备矿）、矿源、原产国、附件；不展示备案号、商品编码、品质参数。**矿源备案** Tab 含备案数量、核销/剩余吨数、用量%；同一矿源多期备案。入库按矿源自动匹配备案；品质参数在库存本票（上架后）展示
- 堆位含库容/占用率；查验完成触发片区标识变更（如 4#A1 待检→混成品）；片区标识变更历史在操作日志页。堆位列表仅展示当前所选仓库（默认 1 仓）。「平面图管理」弹窗约占视口 **60% × 60%**。堆位与功能区为矩形：拖拽、四角缩放、90° 旋转；选中显示虚线框与旋转手柄；网格吸附（可关）；Ctrl+Z / Ctrl+Y 撤销重做；松手边缘吸附且不重叠。名称随矩形宽高自动横排或竖排。平面图保存到后端接口。功能区用于设备间/过道。取消/保存。
- 移库页提供批量移库操作入口；库存页提供报关单号/生产批次号重量台账详情；预警页按 **库容 70%**、**原料库龄 90 天** 规则展示。
- 关务页提供账实差异穿透明细；对接配置页**必预留海关、物流端口**，扩展园区/ERP/生产系统。
- 操作日志页提供修改前后值、业务单号、来源地址和关务专用账号标识等审计详情；筛选支持**时间段**（起止日期）与模块快捷标签。
- 上述补充界面沿用浅色企业后台表格、弹窗、状态 Badge 和 8px 间距体系，不修改基础组件默认视觉。

### 5.2 投标截图规范

- 统一采用 1440×900 浏览器视口，登录后以系统管理员视角截图，必要时切换海关专用账号。
- 十大模块分别形成一组截图；范围较大的基础数据、库存模块可采用主页面与弹窗组合图。
- 截图应保留侧栏、面包屑、模块说明和关键字段，隐藏浏览器无关区域；图中文字须在 A4 页面 15.5cm 宽度下可辨认。
- 文件按 `01-基础数据` 至 `10-安全留痕` 编号，PNG 格式保存于投标截图目录，Word 图题与文件编号一致。

## 6. 可视化驾驶舱（主页专属）

仅登录后首页启用深色科技风；其余业务页保持第 2 节浅色企业后台，避免作业列表可读性下降。

### 6.2 布局（12 栅格）

- 顶栏：标题「保税仓储可视化驾驶舱」+ 实时时钟 + LIVE 心跳
- KPI 条：6 张指标卡（原料湿/干吨、成品干/湿吨、今日入库、今日出库、待检、预警）
- 中左（8 列）：仓库堆位示意图（1/2/4/5/6 仓卡片，展示堆位及片区标识）
- 中右（4 列）：仓储作业链路（日志滚动）+ **生产数据**卡片（基于原图循环施工视频 + 生产批次号/总量/累计重量 KPI）
- 底栏：近 7 日入出库趋势、仓库库容构成、预警

### 6.3 交互

- 堆位悬停：编码、片区标识、物料、占用率、库容
- 点击仓库 3D 模型：未设置平面图则不弹出；已设置则展示堆位分布图，并按各堆位在库重量划分空间、标注物料（委托方/矿种/产地/重量）
- KPI / 预警点击跳转对应业务页
- 作业链路日志自动向上滚动播放，悬停暂停
- 生产全链路节点按序高亮，连线虚线流动
- 进入驾驶舱时数字滚动、热力微动；离开后停止定时器
- 顶栏、内容区在驾驶舱页切换为深色 HUD，侧栏保持原深色并加强青色描边
