# WMS 保税仓储管理系统 — UI 设计

## 1. 设计原则

- 企业级仓储后台：信息密度适中，表格操作为主
- 左侧导航 + 顶栏 + 内容区三栏结构
- 列表页：筛选区 → 操作栏 → 数据表 → 分页
- 表单页/抽屉：分区字段组，必填标识清晰

## 2. 视觉规范

| Token | 值 | 用途 |
|-------|-----|------|
| `--color-primary` | `#1B4F8A` | 主色、侧栏、主按钮 |
| `--color-primary-hover` | `#153D6B` | 悬停 |

## 3. 布局

- 侧栏宽：220px，折叠 64px
- 顶栏高：56px
- 内容区内边距：20px
- 表格行高：约 44px

## 4. 组件规范（原型内）

- Button：主按钮 / 次按钮 / 文字按钮 / 危险按钮
- Input、Select、Date、Upload
- Table + 分页 + 状态 Badge
- Modal / Drawer 表单
- Toast（提示条）
- Empty、Loader
- **原型批注**（评审用）：顶栏「显示/隐藏批注」+ 「批注列表」侧栏；**右键页面任意处**添加批注；弹窗仅输入框；橙色序号 Pin；**完成后 Pin 自动隐藏**，列表可查看；点击列表项定位并高亮落点；**远程同步**统一走线上 `http://wms.skd.wang/api/annotations`（本地预览同样请求该地址，线上同源仍用相对路径）；本地缓存兜底；支持导出/导入 JSON

## 5. 页面清单（原型）

1. 登录（无生产员）；系统设置可全站注册账号；登录态存 `sessionStorage`（`wms_auth`），同标签页刷新保持，退出清除
2. **可视化驾驶舱（主页）**：科技风 HUD，仓库堆位热力 / 入出库趋势 / 作业流水 / 关务账实 / 预警
3. 基础数据：仓库管理（1/2/4/5/6 仓及码头仓库；列表含面积㎡，仅展示可编辑）、堆位管理（单仓库展示；档案列不含报关单号/生产批次/占用率/查验状态；各堆位网格行列）、物料档案、往来主体（**流向企业由出库字段自动录入**；**不含统一社会信用代码**）、保税账册（**货值、报关单号**；点击编号查看票矿并可导出；新账填旧账预警日，旧账只出不进）、系统参数与角色（配置权限弹窗按菜单分组勾选）、**账号管理**（全站注册，无所属关区）、**平面图设置**（系统设置 Tab：左侧画板 / 右侧功能区）
4. 入库：预约/收货列表（筛选：时间范围、货运方式、矿种；状态：**暂存码头 / 待收货 / 已入库 / 混成品**；列含矿种、五项有害元素、装运方式、柜数；**无片区标识**）、收货登记、预定堆位（弹窗右侧、**可关键字搜索**）及**按平面图格子圈选存放位置**、**OCR 回填**；原料库存批次取**报关单号**；已入库/混成品「详情」查看本票单证
5. 移库：先选原堆位再选批次；批量每票单独成单；列表含船名、柜数；移库时间为起止到时；无操作人/详情
6. 库存：多维查询（时间范围：**本月**或自定义起止精确到时）、货物类型原料为达标矿/报备矿、**成品为混成品**、本票品质 **八项**（Cu/Ag/Au/As/Pb/Cd/F/Hg）、成品详情仅**出库报关单/品质证书**、盘点（**可按月份导出各委托方在库数量、堆位、货物类型、提单号、报关单号**）、按报关单号/生产批次号的重量台账（出库记**流向企业**）、预警；列表**不含类型列**；**成品原产国为 —**；**已出库堆位为 —**
7. 生产：投料、加工、完工入库、台账；**同一生产批次号可勾选多个报关单号矿物**；投料列表含**出库报关单号**；物料/船名航次/提单号/来源国家在详情；投料/加工展示**达标矿/报备矿**；成品库存批次即生产批次号
8. 出库：订单列表与审核；**OCR 回填**（出库报关单 → 报关单号/核注清单号/流向企业/**消费使用单位**/重量/**报关单金额**）；列表**时间范围**筛选；识别字段均可手工修正并**操作留痕**；备注选填
9. 关务：账实对账、差异报表
10. OCR 中心
11. 对接配置
12. 操作日志审计

### 5.1 投标功能响应原型补充

- **物料档案**页：原料货物类型（达标矿/报备矿）、成品货物类型**混成品**、矿源；不展示原产国、备案号、商品编码、品质参数。工具栏可**导出 Excel**（编码/名称/货物类型/类型/矿源）。**矿源备案** Tab 含备案原产国、备案数量、核销/剩余吨数、用量%、**附件**；备案编号可点击查看该备案下全部票货并可导出 Excel；同一矿源多期备案。入库按矿源自动匹配备案；品质参数在库存本票（上架后）展示
- 仓库管理列表展示编号、库容、**面积(㎡)**、堆位数、占用率；面积仅档案展示，弹窗可编辑，不参与库容占用计算。堆位档案列表展示编码、所属仓库、片区标识、网格、库容、状态（不展示报关单号、生产批次、占用率、查验状态）；**网格行列取自平面图设置中该堆位所占画板格**，档案页只读；查验完成触发片区标识变更（如 4#A1 待检→混成品）；片区标识变更历史在操作日志页。堆位列表仅展示当前所选仓库（默认 1 仓）。园区平面图改到**系统设置 · 平面图设置**：左右布局，左侧网格画板，右侧工具（网格密度为行×列、仓库/停用仓/办公楼/功能区/生产线/门/堆位/道路/灌木）；道路与灌木为图标重复铺贴；**仓库标号（1# / 2# / 4# / 5# / 6#）标在仓库矩形下方居中**，堆位名称在左下角且不带仓号前缀，**堆位背景默认白色**；**仓库默认 `#f8e4c5`**，**门默认 `#9ebce9`**；门 / 设备间 / 功能区 / 生产线 / 办公楼名称居中并可设颜色，**生产区（生产线/功能区）字号随块大小缩放并允许换行（窄条竖排）**；仓库为外层，内可嵌套生产线、门、堆位；**门始终绘制在最上层**；缩放仓库时内部堆位同步缩放。画板支持滚轮缩放与右上角 − / + 缩放条（无「适应」），放大后拖拽平移整图（空白处 / 右键 / 空格），点选后再拖可移动图形（**平移不改变宽高**，仅四角手柄缩放）。拖拽平移按格线对齐位置；四角缩放、**网格吸附按当前行×列格线对齐四边**（改密度后以新格线为准）、Ctrl+Z / Ctrl+Y。画板网格密度（行×列）随「保存平面图」写入 `park` 的 `gridRows`/`gridCols`，再次打开平面图设置时还原。保存到后端 `park` 平面图。
- 移库页：先选原堆位再选批次；批量移库每票单独成单；列表含船名、柜数与起止到时，无操作人/详情。库存页提供报关单号/生产批次号重量台账详情（出库流水含流向企业）；预警页按 **库容 70%**、**原料库龄 90 天**、**码头仓库 7 天** 规则展示。系统参数含码头仓库预警天数（默认 7）。
- 关务页提供账实差异穿透明细；对接配置页**必预留海关、物流端口**，扩展园区/ERP/生产系统。
- 操作日志页提供修改前后值、业务单号、来源地址和关务专用账号标识等审计详情；筛选支持**时间段**（起止日期）与模块快捷标签；日志**永久留存**，系统参数不配置保留年限。系统参数 Tab 仅含库容预警、原料库龄、矿源备案用量预警、品质参数配置，不含盘点差异自动生成。
- 上述补充界面沿用浅色企业后台表格、弹窗、状态 Badge 和 8px 间距体系，不修改基础组件默认视觉。

### 5.2 投标截图规范

- 统一采用 1440×900 浏览器视口，登录后以系统管理员视角截图，必要时切换海关专用账号。
- 十大模块分别形成一组截图；范围较大的基础数据、库存模块可采用主页面与弹窗组合图。
- 截图应保留侧栏、面包屑、模块说明和关键字段，隐藏浏览器无关区域；图中文字须在 A4 页面 15.5cm 宽度下可辨认。
- 文件按 `01-基础数据` 至 `10-安全留痕` 编号，PNG 格式保存于投标截图目录，Word 图题与文件编号一致。

仅登录后首页启用深色科技风；其余业务页保持第 2 节浅色企业后台，避免作业列表可读性下降。

### 6.2 布局（12 栅格）

- 顶栏：标题「保税仓储可视化驾驶舱」+ 实时时钟 + LIVE 心跳
- KPI 条：6 张指标卡（原料湿/干吨、成品干/湿吨、今日入库、今日出库、待检、预警）
- 中左（8 列）：仓库堆位示意图（放大展示 5 仓拼接园区平面图，上层绘制各堆位格子的在库货物与入库预约）
- 中右（4 列）：仓储作业链路（加高日志滚动区，时间精度到「年月日时」、不含分钟）+ **生产数据**卡片（基于原图循环施工视频 + 生产批次号/总量/累计重量 KPI）
- 底栏：近 7 日入出库趋势（图例统一为入库湿吨 / 出库湿吨）、**仓库使用分布**（各仓库占用进度条，无饼图）、预警（与作业链路相同：无缝循环向上滚动，悬停暂停）

### 6.3 交互

- 堆位悬停：编码、片区标识、物料、占用率、库容、预约格数
- 点击堆位（空闲格/堆位块）进入堆位管理；点击在库矿物格子跳转库存查询并定位该票；平面图仓库本身不可点击跳转；**仓库/生产区/堆位填色与平面图设置一致**（堆位默认白底）；在库矿物按货主分色（南国铜业绿、五矿有色黄、广西金川蓝），达标矿浅色、报备矿深色，混成品灰色；入库预约格子青色描边
- 首页平面图在远程数据返回前显示工业风扫描加载（雷达/格线/扫描条），不先绘制默认园区图再替换；加载动画至少展示 2 秒
- KPI / 预警点击跳转对应业务页
- 作业链路日志自动向上滚动播放，悬停暂停；时间展示为 `yyyy-mm-dd HH时`
- 底栏预警列表同样无缝循环向上滚动，悬停暂停；点击条目跳转对应业务页
- 生产全链路节点按序高亮，连线虚线流动
- 进入驾驶舱时数字滚动、热力微动；离开后停止定时器
- 顶栏、内容区在驾驶舱页切换为深色 HUD，侧栏保持原深色并加强青色描边
