## 第一阶段（D1–D30）：WMS 功能开发

对应功能分批 **第一至四批**；内部按 Sprint 推进，与合同节点对齐。

### D1–D5：启动与需求基线

- [ ] 成立专项小组，确认项目经理与甲方对口人
- [ ] 需求调研与澄清：五仓片区结构、铜精矿档案字段、干湿重规则、账册口径、角色权限、**海关/物流接口边界**
- [ ] 输出并双方确认：需求确认单、流程说明、数据字典、权限矩阵、接口清单
- [ ] 信创环境规划：确认 CPU 架构（鲲鹏/aarch64）、JDK 版本、Vastbase 实例授权
- [ ] 工程初始化：**Java Spring Boot** + Flyway（PostgreSQL 方言）+ JWT；前端登录鉴权、布局与权限路由

**交付物**：需求确认单、项目基线、工程骨架可运行

### D6–D10：第一批 — 基础数据、权限与审计

- [ ] 五仓及仓库—堆位档案 CRUD；**片区标识**随在库批次（报关单号/生产批次号）查验自动变更与历史留痕
- [ ] 铜精矿档案（原料达标矿/报备矿、**成品混成品**）+ **矿源备案** CRUD（矿山、原产国、备案数量、附件；报备矿引用矿源，入库自动匹配备案）；干湿重、报关单/核注清单映射；品质参数记入上架后本票库存
- [ ] 往来主体（委托方、物流账册主体；**流向企业由出库字段自动识别录入**；**不含统一社会信用代码**）、保税账册档案（货值/报关单号/票矿；新旧账衔接与预警转入）
- [ ] 角色权限、海关专用账号隔离、系统参数
- [ ] 操作审计日志（操作人/时间/对象/内容/改前改后/来源地址/业务单号）
- [ ] 等保基线：密码策略、登录锁定、会话超时
- [ ] **信创最小冒烟**：UOS + Vastbase 部署 Java 进程 + 登录 + 一条档案维护流程

**验收点**：编码唯一、权限隔离、启停控制、操作留痕；基础数据模板与权限矩阵确认

### D11–D20：第二批 — 仓储收发存主流程

- [ ] 入库预约/到货（船名、提单号、报关单、核注清单、金额、矿种、五项有害元素、装运方式/柜数；状态暂存码头/待收货/已入库/混成品）
- [ ] 品质单上传与 OCR 识别回填（可先 Mock，D26 前完成信创 POC 冻结）
- [ ] 称重录入湿重/干重、保税账册匹配
- [ ] 按原料/成品/待检属性分配堆位，**原料库存批次取报关单号**并生成库存流水；上架后堆位片区标识随在库批次状态确定
- [ ] 移库（先选原堆位再选批次；批量每票一条；船名/柜数；移库时间到时）
- [ ] 多维库存查询（矿源/账册/原料成品筛选/堆位/片区标识/时间：本月或起止精确到时；列表无类型列；品质八项；成品原产国与已出库堆位为空）
- [ ] 周期盘点、动态抽盘、差异审批；**按月份导出各委托方在库（数量、堆位、货物类型、提单号、报关单号）**
- [ ] 库存预警：**库容 70%**、**原料库龄 90 天**、**码头仓库货品超 7 天**
- [ ] 报关单号 / 生产批次号与干湿重台账（出库流水记录流向企业）
- [ ] 出库订单创建/审核/执行（报关单、核注清单、流向企业、**消费使用单位**、出库时间/重量/**报关单金额**、备注）；列表时间范围筛选；**OCR 识别出库报关单并回填**；OCR 字段可手工修正并留痕
- [ ] Vastbase 复杂查询性能基线测试

**验收点**：连续样本验证库存流水逐笔生成、余额与明细一致；预警规则可触发

### D21–D26：第三批 — 生产完工与关务监管

- [ ] 生产工单：按**生产批次号**投料出库（可用量校验）；**同一生产批次号可挂接多个报关单号矿物**；记录出库报关单号；物料/船名航次/提单号/来源国家在详情；投料列表按报关单展示达标矿/报备矿
- [ ] 加工过程登记（工序、时间、操作人、异常说明）；展示该生产批次下全部报关单号
- [ ] 成品（铜精矿）完工入库，库存批次取**生产批次号**，谱系追溯至各报关单号
- [ ] 原料消耗/成品产出自动汇总台账，支持穿透
- [ ] 关务专用操作界面与权限隔离
- [ ] 账册库存 vs WMS 账面 vs 盘点实物自动对账
- [ ] 差异清单穿透（报关单号/生产批次号/入出库单/生产记录/盘点调整）与报表导出
- [ ] 联网申报、电子账册核销接口预留（受控鉴权、回执归档）

**验收点**：跨入库—生产—出库—关务样本核验原料去向、成品来源、账册数量

### D27–D30：第四批 — OCR、接口与智慧化

- [ ] OCR 全链路：报关单（入库/出库）/提单/品质单/重量单上传 → 识别 → 人工修正（全部识别字段，含出库报关单金额）→ 业务回填 → 附件归档；修正留痕
- [ ] OCR 信创 POC 冻结（UOS + 目标架构验证）
- [ ] 对外接口层：**海关**、**物流**（必交付端口）；园区监管、ERP、生产系统（扩展预留）
- [ ] 接口治理：白名单、HTTPS/专线、令牌/证书、幂等键、重试队列、调用日志
- [ ] 可视化驾驶舱：仓库堆位热力、入出库趋势、作业链路、生产数据卡片、预警
- [ ] 多维汇总报表与自定义模板；指标下钻至报关单号/生产批次号/单据/日志
- [ ] 内部集成测试、权限/异常/接口回归、版本冻结
- [ ] 提交可测评版本、功能清单、测试报告、操作指引、已知问题说明

**验收点**：原图/识别值/修正痕迹可查；接口样例报文可调通；驾驶舱指标可下钻
