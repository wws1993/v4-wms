## 第一阶段（D1–D30）：WMS 功能开发

对应功能分批 **第一至四批**；内部按 Sprint 推进，与合同节点对齐。

### D1–D5：启动与需求基线

- [ ] 成立专项小组，确认项目经理与甲方对口人
- [ ] 需求调研与澄清：五仓片区结构、铜精矿档案字段、干湿重规则、账册口径、角色权限、**海关/物流接口边界**
- [ ] 输出并双方确认：需求确认单、流程说明、数据字典、权限矩阵、接口清单
- [ ] 信创环境规划：确认 CPU 架构（鲲鹏/aarch64）、JDK 版本、Vastbase 实例授权
- [ ] 工程初始化：**Java Spring Boot** + Flyway（PostgreSQL 方言）+ JWT；前端登录鉴权、布局与权限路由

**交付物**：需求确认单、项目基线、工程骨架可运行

### D6–D10：第一批 — 基础数据、权限与审计
