# 保税仓储管理系统（WMS）— 0期原型

依据《新建 文本文档.txt》需求制作的可交互原型（Axure 级页面线框与跳转）。

## 快速打开

双击打开：

`wms/dist/index.html`

或本地静态服务：

```bash
cd wms/dist
npx serve .
```

日常用 XFTP 覆盖服务器上的 `dist/` 与 `api/` 代码即可，**不要上传 `data/`**。说明见 `wms/XFTP上传说明.txt`。

本地打开时批注与平面图请求线上 `http://wms.skd.wang/api/`，与线上共用数据。

## Vue 前端

正式前端在 `frontend/`，与上面的 HTML 原型分开。技术栈为 Vue 3、TypeScript、Element Plus。Figma 只定整体风格；业务页按 UI 设计配色。

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`。登录、验证码、退出请求丰联。`frontend/.env` 里 `VITE_USE_MOCK=false`，并由 `VITE_LIVE_MODULES` 放行已对接模块；驾驶舱汇总、盘点、生产、出库、关务仍用本地 mock。矿源备案、入库、库存查询和移库已请求丰联。平面图整图 JSON 已上传丰联，驾驶舱从服务器读取。说明见 `docs/对接计划.md`。页面上仍预填：

| 账号 | 密码 | 角色 |
|------|------|------|
| admin | admin123 | 系统管理员 |
| warehouse | wh123 | 仓管员 |
| customs | cus123 | 关务员 |

不包含对外对接、开发进度跟踪、系统架构。账号是否能登录以丰联环境为准，页面预填 `admin` / `admin123`。系统设置「系统参数」左侧「安全策略」可调整密码规则、登录锁定和空闲退出，保存在本机浏览器。顶栏用户菜单可修改密码。

## 原型覆盖模块

1. 基础数据：仓库管理（含面积㎡展示、**排序**、**码头仓库**）、堆位管理（含排序，列表按排序号从小到大；网格取自平面图占格，新建/编辑弹窗不展示网格字段）、物料档案（原料达标矿/报备矿、**成品混成品**；按货物类型、类型、编码/名称筛选；新建/编辑仅基础信息，原料手填矿源；可导入 CSV、**可导出 Excel**）、矿源备案（状态为有效/即将用尽/已用尽；弹窗单列，手填矿源和备案编号，含附件；**可按备案日期时间范围筛选**；**备案编号可点开票货并导出 Excel**）、往来主体（**流向企业由出库字段自动录入**，**不含统一社会信用代码**）、系统设置（角色/**账号管理**/参数/**平面图设置**，网格密度为行×列，画板可缩放；区块可标堆位或门（门名顺着长边、字号随宽高缩小；门和同仓堆位按上一块编号顺延，如 3号门之后为 4号门、B1 之后为 B2；拖动区块时设置弹窗先收起，松开后按新位置弹出），保存时同步仓库与堆位档案，并播放白底、跟随主题色的扫描动画，新增仓库填写库容和面积；仓库内绘制堆位按占格百分比向下取整库容，改大小或仓库库容会重算；「初始化」先清空平面图，再按面积估算绘制并留白 30%，右键仓库仍可初始化该仓堆位；堆位白色、拖拽不改尺寸、生产区文字可换行）
2. 入库：预约/收货（时间范围、货运方式、矿种筛选；状态暂存码头/待收货/已入库/混成品；矿种、装运方式/柜数；预约与到货登记不含五项有害元素；无片区标识）、OCR、预定堆位
3. 移库：先选原堆位再选批次；批次信息表格只读；批量可跨仓查询勾选；列表按委托方/日期筛选；每票一条；移库时间到时
4. 库存：多维查询（单号、委托方、货物类型、堆位，更多条件含物料类型、原产国、备案号、账册、仓库；时间不限、本月或自定义到时；**列表分页**；**原料达标矿/报备矿、成品混成品**；品质八项；无类型列；成品原产国/已出库堆位为 —；本票详情按原型附识别影像（可拖动、缩放、旋转）；原料含成品去向，成品详情为出库报关单、品质证书和成品页）、盘点（范围可多选仓库/堆位，可上传附件，不回写库存；**可按月导出各家在库数量/堆位/货物类型/提单号/报关单号**）、报关单号/生产批次号重量台账（出库记流向企业）、库容/库龄/**码头仓库超 7 天**预警（在库存预警，不另设预警日志）
5. 生产加工：在仓储作业菜单中。投料与加工合为一项，投料按报关单一行（湿重/本次干吨、出库报关单号），加工按起止时刻一行。详情为生产批次下的报关单表和完工信息。加工登记含混矿原料信息和备注。完工入库填写成品物料和产量，只进入待检区；查验完成在堆位管理。消耗产出台账可按日看明细
6. 出库：创建与审核；**消费使用单位**；列表**时间范围**筛选；支持扫描出库报关单 OCR 回填（含报关单金额）；识别字段可手工修正并留痕；备注选填
7. 关务保税：账实对账、差异穿透、联网申报与电子账册核销预留
8. 账务：保税账册为左侧账册、右侧账册记录，备案只填编号、名称和旧账预警日，默认衔接在用账册，保存后旧账册停用并只结转在册未出库票货；月度账册只查询、可导出（当月有耗用即全额出清，次月不再纳入）。月度账册按当前筛选下载 CSV，详情可看原料存储、加工、出库
9. OCR 识别中心
10. 对外对接配置：园区、企业 ERP、生产与海关端口
11. 系统：字典管理在操作日志上方（字典类型与字典值可增删改，可刷新缓存）。操作日志审计：业务单号、来源地址和修改前后值
12. **开发进度跟踪**：按能力跟踪表提交六轨进度；甘特图与柱状图分维度同步分析；变更日志记录修改者、来源 IP 与修改时间
13. **可视化驾驶舱（主页）**：科技风 HUD。仓库堆位示意图右上角切换 立体图 / 平面图，切换时交叉叠化。立体图为斜视仓库卡片，每仓一块等轴库房，下方一排堆位方块；有预警的仓库闪红边；移入弹窗不跳转，点击仓库进入该仓平面图。平面图为放大的五仓拼接（加载中为工业风扫描至少 2 秒，不闪默认图；默认整园；点仓库/堆位仅绘制该仓，总览移入仓库、放大后移入堆位会弹出占用和库存，放大后点堆位进管理、点矿物查该票，左上角回退） / 入出库趋势（湿吨） / 加高作业链路（时间到小时） / 关务账实 / 预警（循环滚动）

登录页可切换仓管员 / 关务员 / 管理员，也可使用系统设置中注册的账号。仓管员、关务员与管理员登录后进入驾驶舱。

## 正式环境约束（预告）

正式交付须满足信创适配与等保要求：运行环境为 **统信服务器操作系统 + 海量数据库（Vastbase）**，后端为 **Java（Spring Boot）**。开发阻碍、规避原则与分期安排见 `docs/项目设计.md` §7、`docs/开发计划.md`、`docs/部署指南.md`。
