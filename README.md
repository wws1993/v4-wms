# 保税仓储管理系统（WMS）— 0期原型

依据《新建 文本文档.txt》需求制作的可交互原型（Axure 级页面线框与跳转）。

## 快速打开

双击打开：

`wms/dist/index.html`

或本地静态服务：

```bash
cd wms/dist
npx serve .
```

日常用 XFTP 覆盖服务器上的 `dist/` 与 `api/` 代码即可，**不要上传 `data/`**。说明见 `wms/XFTP上传说明.txt`。

本地打开时批注与平面图请求线上 `http://wms.skd.wang/api/`，与线上共用数据。

## Vue 前端

正式前端在 `frontend/`，与上面的 HTML 原型分开。技术栈为 Vue 3、TypeScript、Element Plus。Figma 只定整体风格；业务页按 UI 设计配色。默认使用本地 mock，不请求真实后端。

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`。演示账号：

| 账号 | 密码 | 角色 |
|------|------|------|
| admin | admin123 | 系统管理员 |
| warehouse | wh123 | 仓管员 |
| customs | cus123 | 关务员 |

不包含对外对接、开发进度跟踪、系统架构。后端就绪后把 `frontend/.env` 里的 `VITE_USE_MOCK` 改为 `false`，并设置 `VITE_API_BASE`。

## 原型覆盖模块

1. 基础数据：仓库管理（含面积㎡展示、**码头仓库**）、堆位管理（网格取自平面图占格，新建/编辑弹窗不展示网格字段）、物料档案（原料达标矿/报备矿、**成品混成品**；新建/编辑仅基础信息；无原产国/附件，**可导出 Excel**）、矿源备案（含附件与**生产批次号**；**可按备案日期时间范围筛选**；**备案编号可点开票货并导出 Excel**）、往来主体（**流向企业由出库字段自动录入**，**不含统一社会信用代码**）、保税账册（**货值/报关单号**；**编号可点开票矿并导出**；新旧账衔接与预警转入；**可按旧账预警时间范围筛选**）、系统设置（角色/**账号管理**/参数/**平面图设置**，网格密度为行×列，画板可缩放；堆位白色、拖拽不改尺寸、生产区文字可换行）
2. 入库：预约/收货（时间范围、货运方式、矿种筛选；状态暂存码头/待收货/已入库/混成品；矿种、装运方式/柜数；预约与到货登记不含五项有害元素；无片区标识）、OCR、预定堆位
3. 移库：先选原堆位再选批次；批次信息表格只读；批量可跨仓查询勾选；列表按委托方/日期筛选；每票一条；移库时间到时
4. 库存：多维查询（本月或自定义到时；**原料达标矿/报备矿、成品混成品**；品质八项；无类型列；成品原产国/已出库堆位为 —；本票详情含成品去向（产量/库存/出库））、盘点（范围可多选仓库/堆位，可上传附件，不回写库存；**可按月导出各家在库数量/堆位/货物类型/提单号/报关单号**）、报关单号/生产批次号重量台账（出库记流向企业）、库容/库龄/**码头仓库超 7 天**/账实预警
5. 生产/完工：投料与加工合为一项（委托方/时间范围筛选；同一生产批次号可挂多票报关单，展示达标矿/报备矿，含出库报关单号；物料/船名航次/提单号/来源国家在详情）、**完工入库仅入待检区、查验完成改为成品区**、台账
6. 出库：创建与审核；**消费使用单位**；列表**时间范围**筛选；支持扫描出库报关单 OCR 回填（含报关单金额）；识别字段可手工修正并留痕；备注选填
7. 关务保税：账实对账、差异穿透、联网申报与电子账册核销预留
8. OCR 识别中心
9. 对外对接配置：园区、企业 ERP、生产与海关端口
10. 操作日志审计：业务单号、来源地址和修改前后值
11. **开发进度跟踪**：按能力跟踪表提交六轨进度；甘特图与柱状图分维度同步分析；变更日志记录修改者、来源 IP 与修改时间
12. **可视化驾驶舱（主页）**：科技风 HUD，放大的五仓拼接园区平面图（加载中为工业风扫描至少 2 秒，不闪默认图；默认整园，卫星图开关切换航拍风格；点仓库/堆位仅绘制该仓，放大后点堆位进管理、点矿物查该票，左上角回退） / 入出库趋势（湿吨） / 加高作业链路（时间到小时） / 关务账实 / 预警（循环滚动）

登录页可切换仓管员 / 关务员 / 管理员，也可使用系统设置中注册的账号。仓管员、关务员与管理员登录后进入驾驶舱。

## 正式环境约束（预告）

正式交付须满足信创适配与等保要求：运行环境为 **统信服务器操作系统 + 海量数据库（Vastbase）**，后端为 **Java（Spring Boot）**。开发阻碍、规避原则与分期安排见 `docs/项目设计.md` §7、`docs/开发计划.md`、`docs/部署指南.md`。

## 说明

本仓库 0 期交付为 **HTML 可交互原型**，便于评审与走查。若需导入 Axure RP 继续编辑，可按侧栏页面结构在 Axure 中逐页还原；需要的话可再补一版 Axure 页面清单/组件对照表。
