# 保税仓储管理系统（WMS）— 0期原型

依据《新建 文本文档.txt》需求制作的可交互原型（Axure 级页面线框与跳转）。

## 快速打开

双击打开：

`wms/dist/index.html`

或本地静态服务：

```bash
cd wms/dist
npx serve .
```

日常用 XFTP 覆盖服务器上的 `dist/` 与 `api/` 代码即可，**不要上传 `data/`**。说明见 `wms/XFTP上传说明.txt`。

本地打开时批注与平面图请求线上 `http://wms.skd.wang/api/`，与线上共用数据。

## 原型覆盖模块

1. 基础数据：仓库管理（含面积㎡展示、**码头仓库**）、堆位管理（网格取自平面图占格）、物料档案（原料达标矿/报备矿、**成品混成品**；无原产国/附件，**可导出 Excel**）、矿源备案（含附件；**备案编号可点开票货并导出 Excel**）、往来主体（**流向企业由出库字段自动录入**，**不含统一社会信用代码**）、保税账册（**货值/报关单号**；**编号可点开票矿并导出**；新旧账衔接与预警转入）、系统设置（角色/**账号管理**/参数/**平面图设置**，网格密度为行×列，画板可缩放；堆位白色、拖拽不改尺寸、生产区文字可换行）
2. 入库：预约/收货（时间范围、货运方式、矿种筛选；状态暂存码头/待收货/已入库/混成品；矿种、五项有害元素、装运方式/柜数；无片区标识）、OCR、预定堆位
3. 移库：先选原堆位再选批次；批量每票一条；船名/柜数；移库时间到时
4. 库存：多维查询（本月或自定义到时；**原料达标矿/报备矿、成品混成品**；品质八项；无类型列；成品原产国/已出库堆位为 —；成品详情仅出库报关单与品质证书）、盘点差异审批（**可按月导出各家在库数量/堆位/货物类型/提单号/报关单号**）、报关单号/生产批次号重量台账（出库记流向企业）、库容/库龄/**码头仓库超 7 天**/账实预警
5. 生产/完工：投料（同一生产批次号可挂多票报关单，展示达标矿/报备矿，含出库报关单号；物料/船名航次/提单号/来源国家在详情）、加工、完工入库、台账
6. 出库：创建与审核；**消费使用单位**；列表**时间范围**筛选；支持扫描出库报关单 OCR 回填（含报关单金额）；识别字段可手工修正并留痕；备注选填
7. 关务保税：账实对账、差异穿透、联网申报与电子账册核销预留
8. OCR 识别中心
9. 对外对接配置：园区、企业 ERP、生产与海关端口
10. 操作日志审计：业务单号、来源地址和修改前后值
11. **可视化驾驶舱（主页）**：科技风 HUD，放大的五仓拼接园区平面图（加载中为工业风扫描至少 2 秒，不闪默认图；点堆位进管理、点矿物查该票库存） / 入出库趋势（湿吨） / 加高作业链路（时间到小时） / 关务账实 / 预警（循环滚动）

登录页可切换仓管员 / 关务员 / 管理员，也可使用系统设置中注册的账号。仓管员、关务员与管理员登录后进入驾驶舱。

## 正式环境约束（预告）

正式交付须满足信创适配与等保要求：运行环境为 **统信服务器操作系统 + 海量数据库（Vastbase）**，后端为 **Java（Spring Boot）**。开发阻碍、规避原则与分期安排见 `docs/项目设计.md` §7、`docs/开发计划.md`、`docs/部署指南.md`。

本仓库 0 期交付为 **HTML 可交互原型**，便于评审与走查。若需导入 Axure RP 继续编辑，可按侧栏页面结构在 Axure 中逐页还原；需要的话可再补一版 Axure 页面清单/组件对照表。
